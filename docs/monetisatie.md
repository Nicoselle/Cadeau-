# Monetisatie

Freemium blijft het industrie-standaardkader (~45% van de wereldwijde
astrologie-appomzet). Azimut mikt op het premium prosumer-segment.

| Laag | Wat de gebruiker krijgt | Prijsrichting |
|---|---|---|
| Free | Career type, dominant sectorkanaal, RAE-risicoklasse | €0 |
| Report | Eenmalig dossier + hiring mandate + timing | €29–€79 |
| Pro | Cycli, transits, maandbriefing | ~€37/maand |
| Team | Penta / mede-oprichter-synastrie, skill gaps | enterprise |

De huidige MVP toont het volledige dossier zonder paywall, zodat het
algoritme beoordeeld kan worden. De paywall-snede is: gratis type + sector +
risico; de rest achter Pro.
