# Preuve AI

A functional MVP of a startup-idea validation tool. Describe an idea in a
sentence and get back a viability report — a 0–100 score, go/caution/no-go
verdict, competitor map, market sizing (TAM/SAM/SOM), demand signals, risks, and
three pivots — generated by Claude.

> This is a demo. Report figures (competitors, funding, market sizes, sources)
> are **AI-generated estimates**, not live-scraped data. Verify anything
> important before you build.

## Stack

- **Next.js** (App Router) + **TypeScript** + **Tailwind CSS**
- **Anthropic SDK** (`@anthropic-ai/sdk`) for the validation engine

## How it works

1. The landing page (`app/page.tsx`) takes an idea and routes to
   `/validate?idea=…`.
2. `components/ValidateClient.tsx` shows an agent-style loading sequence and
   `POST`s the idea to `app/api/validate/route.ts`.
3. The API route calls Claude with a single **forced tool** (`lib/prompt.ts`),
   whose input schema mirrors the `ValidationReport` type (`lib/report.ts`). This
   guarantees a validated, structured object — no fragile JSON parsing.
4. `components/report/ReportView.tsx` renders the dashboard.

## Setup

```bash
npm install
cp .env.example .env.local   # then set ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

### Environment variables

| Variable            | Required | Default          | Notes                                        |
| ------------------- | -------- | ---------------- | -------------------------------------------- |
| `ANTHROPIC_API_KEY` | Yes\*    | —                | \*Needed at runtime to generate reports.     |
| `ANTHROPIC_MODEL`   | No       | `claude-opus-4-8`| Override the model used for validation.      |

The production build (`npm run build`) does **not** require a key; only report
generation at runtime does.

## Scripts

```bash
npm run dev     # dev server
npm run build   # production build + type-check
npm run start   # serve the production build
```

## Project structure

```
app/
  layout.tsx            Root layout + metadata
  page.tsx              Landing page
  globals.css           Tailwind + design tokens
  validate/page.tsx     Results page (Suspense wrapper)
  api/validate/route.ts POST { idea } -> Claude -> structured report
components/
  IdeaInput.tsx         Hero idea textarea + CTA
  ScoreGauge.tsx        Score ring + verdict badge
  ValidateClient.tsx    Loading sequence + fetch + render
  marketing/            Hero, StatsStrip, FeatureGrid, HowItWorks, Footer
  report/ReportView.tsx Full report dashboard
lib/
  report.ts             ValidationReport types (shared)
  anthropic.ts          Anthropic client + model constant
  prompt.ts             System prompt + report tool schema
```

## Scope

This MVP is intentionally focused: no payments, no auth, no live data sources,
no monitoring. Those are the parts of the real product that are out of scope
here.
